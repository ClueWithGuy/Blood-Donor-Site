Built by students who kept losing this race

Drop For Life started as a section-E class project after one too many midnight scrambles to find a compatible donor before visiting hours ended. It's a directory, a request board, and a donor's donation record, in one place.

  • No donor pays or gets paid — this is a mutual-aid directory, not a marketplace.
  • Availability is opt-in and can be switched off at any time.
  • Location is only shared while a donor is marked available.
